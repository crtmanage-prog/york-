# Контент Trial Lesson Hub

Страница `trial-hub.html` сама ничего не хранит: всё, что видит преподаватель,
берётся из JSON-файлов в этой папке. Новая тема, активность или материал —
это новый объект в нужном файле, код страницы трогать не нужно.

После правки проверьте страницу: если в JSON ошибка (лишняя запятая,
пропущенная кавычка), Hub покажет, в каком файле проблема. Запись без
обязательных полей не ломает страницу — она пропускается и выводится
в жёлтом списке сверху.

## lessons.json — банк микро-тем

Массив тем. Обязательные поля отмечены *.

| Поле | Что это |
|---|---|
| `id`* | уникальный латинский ключ, например `b1-used-to`. Не меняйте после публикации — на него ведут ссылки учеников |
| `level`* | `A0-A1`, `A2`, `B1`, `B2` или `C1` |
| `category`* | `grammar`, `natural`, `speaking`, `work`, `vocabulary`, `fluency` (список — в `meta.json`) |
| `title`* | название темы |
| `outcome`* | результат ученика: «Я могу…» |
| `icon` | один эмодзи |
| `section` | раздел внутри уровня |
| `idea` | идея / простое объяснение |
| `leadIn` | вопрос для начала темы |
| `explanation` | список ключевых фраз и примеров |
| `practice` | что делать на практике (видит только преподаватель) |
| `speaking` | вопрос для разговорной практики |
| `mistakes` | типичные ошибки: `[["неправильно", "правильно"], …]` — тогда тема попадёт в Grammar Topics с блоком ошибок |
| `lesson` | интерактивный урок для кнопки «Show to student» (см. ниже) |

### lesson — интерактивный урок

Шаги собираются сами: Разминка → Тема → Схема → Задания → Говорим → Итог.
Любой блок можно не указывать.

- `warmup` — вопросы для разминки: `["How are you?", …]`
- `visual` — схема, `type` один из:
  - `compare` — две колонки: `cols: [{icon, label, sub, examples: []}]`
  - `formula` — цепочка: `parts: [{t, ex}]`
  - `scale` — шкала: `steps: [{w, d}]`
  - `upgrade` — было → стало: `pairs: [["было", "стало"]]`
  - `table` — строки: `rows: [["эмодзи", "текст", "текст"]]`
  - `note` — подсказка внизу (необязательно)
- `tasks` — задания, `type` один из:
  - `choose` — выбор: `items: [{pic, q, options, a}]`, пропуск в `q` — `___`, `a` — номер верного варианта с нуля
  - `build` — собрать предложение: `items: ["Готовое предложение."]`
  - `match` — пары: `pairs: [["слева", "справа"]]`
  - `reveal` — сказать и проверить: `title`, `items: [{q, a}]`
- `speak` — задания на речь: `[{q, hint}]`, у каждого таймер на минуту

Проще всего скопировать похожую тему целиком и поменять тексты.

## activities.json — разговорные активности

`categories` — разделы (Icebreakers, Discussions, Role plays, Speaking games).
`items` — активности: `id`*, `category`*, `title`*, `levels`* (список уровней),
`play`* (экран для ученика), `icon`, `sub` (подраздел, например Work),
`goal`, `how` (для преподавателя), `rules`, `phrases` (для ученика).

Типы `play.type`: `truths`, `rather`, `findwho`, `opinions`, `ranking`,
`debate`, `situations` (ролевые игры), `minute`, `picture`, `detective`, `exit`.
Новую ролевую игру проще всего сделать копией любой `rp-…`.

## translations.json — переводы на русский

Словарь «английский текст → перевод». Hub сам показывает перевод серой
строкой под английской фразой — в карточках и в уроке для ученика.
Ключ должен совпадать с английским текстом символ в символ (включая ’ и …).
Если перевода нет, фраза просто показывается без него.

Когда добавляете новую тему или активность, допишите сюда переводы
её фраз, вопросов и заданий. Для предложений с пропуском `___` пишите
перевод целого предложения — ученик увидит его только после правильного ответа.

Переключатель «Перевод: вкл/выкл» есть в меню и на экране урока.

## Остальные файлы

- `meta.json` — уровни, их названия и цели, категории, универсальные темы,
  быстрый выбор по ситуации ученика (`situations[].topics` — список id тем).
- `structure.json` — главная цель, принципы, таймлайн урока (`timeline`),
  «что должен почувствовать ученик» (`experience`).
- `checklist.json` — чек-лист преподавателя по группам.
- `materials.json` — материалы. Пока `url: null` — на карточке кнопка
  «Link coming soon». Впишите ссылку — появится кнопка «Open».
